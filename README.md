# 🛍️ ShopEase – Fashion E-Commerce Website

A modern and responsive fashion e-commerce website designed to provide a smooth and engaging online shopping experience. ShopEase features product browsing, search functionality, wishlist UI, delivery location support, user login, promotional banners, and responsive design.

## ✨ Features

* 🛒 Fashion e-commerce interface
* 🔍 Product search functionality
* ❤️ Wishlist interface
* 📍 Delivery location & pincode support
* 👤 User login interface
* 🎨 Promotional banners and offers
* 📱 Responsive design
* 🧭 Easy navigation
* 💬 Customer support section
* 📦 Product categories and shopping sections

## 🛠️ Technologies Used

* 🌐 **HTML5** – Website structure
* 🎨 **CSS3** – Styling, layouts and responsive design
* ⚡ **JavaScript** – Interactive functionality
* 🔤 **Font Awesome** – Icons
* 🚀 **Netlify** – Deployment
